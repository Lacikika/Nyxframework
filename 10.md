## 1. Unified Single-Frame Architecture (`nyx_ui`)

Legacy FiveM frameworks spawn 10–20 individual resource `ui_page` iframes. This burns VRAM, desynchronizes input states, and produces disjointed styles. `Nyxframework` routes all client-facing UI through a **single persistent master frontend shell**.

  

```
                           FiveM Native Runtime
                                    │
                         [SendNUIMessage / NuiCallback]
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   nyx_ui Master App (React / Svelte)                   │
├────────────────────────────────────────────────────────────────────────┤
│  Global State Store (Zustand / Pinia) & Master Theme Engine (Tailwind) │
├───────────────┬────────────────┬─────────────────┬─────────────────────┤
│  [Inventory]  │   [Context]    │ [Notifications] │   [Citizen Phone /  │
│  Slot Matrix  │ Radial Target  │ & Status Toasts │       MDT App]      │
├───────────────┼────────────────┼─────────────────┼─────────────────────┤

```

### 1.1 Wire Protocol & Message Contract

Every interaction between the Lua/JS game runtime and the NUI shell uses a single standardized envelope:

  

TypeScript

```
// Shared NUI Message Contract
interface NyxNuiPacket<T = unknown> {
  app: 'inventory' | 'radial' | 'hud' | 'dialog' | 'parliament' | 'judiciary' | 'factions';
  action: string;
  payload: T;
}
```

#### Dispatching from Game Runtime:

Lua

```
-- client/bridge.lua
function Nyx.UI.Send(app, action, payload)
    SendNUIMessage({
        app = app,
        action = action,
        payload = payload or {}
    })
end
```

#### Inbound Callback Router:

JavaScript

```
// web/src/bridge/transport.ts
export async function postNui<TRequest, TResponse>(action: string, data: TRequest): Promise<TResponse> {
  const resp = await fetch(`https://${GetParentResourceName()}/${action}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json; charset=UTF-8' },
    body: JSON.stringify(data)
  });
  return await resp.json();
}
```

## 2. Spatial Raycasting Engine (`nyx_interact`)

Replaces legacy 3D coordinate marker draw loops with an event-driven screen-to-world raycast targeting system.

  

### 2.1 The Dynamic Raycast Calculation

The target thread stays **dormant** ($0.00\text{ ms}$) until the player activates the interaction bind (e.g., holding `LALT`).

  

Lua

```
-- client/raycast.lua
function Nyx.Interact.CastCameraRay(distance)
    local camRot = GetGameplayCamRot(2)
    local camCoord = GetGameplayCamCoord()
    
    local forwardVector = Nyx.Math.RotationToDirection(camRot)
    local targetCoord = camCoord + (forwardVector * distance)

    local rayHandle = StartShapeTestLosProbe(
        camCoord.x, camCoord.y, camCoord.z,
        targetCoord.x, targetCoord.y, targetCoord.z,
        -1, -- Flag: intersect peds, vehicles, objects, world collision
        PlayerPedId(),
        4   -- Options: see-through materials ignored
    )

    local _, hit, endCoords, surfaceNormal, entityHit = GetShapeTestResult(rayHandle)
    return hit == 1, entityHit, endCoords
end
```

### 2.2 Target Registry Specification

Entities, world models, and spatial bounding boxes declare interaction options declaratively without per-frame client loops:

  

Lua

```
-- Adding an eye-target hook to commercial freight pallets
exports['nyx_interact']:AddTargetModel({ `prop_boxpile_06a`, `prop_pallet_01a` }, {
    options = {
        {
            icon = 'fa-solid fa-dolly',
            label = 'Move Pallet',
            action = function(entity)
                TriggerEvent('nyx:logistics:movePallet', entity)
            end,
            canInteract = function(entity, distance)
                return distance < 2.0 and not IsPedInAnyVehicle(PlayerPedId(), true)
            end
        },
        {
            icon = 'fa-solid fa-box-open',
            label = 'Inspect Inventory',
            action = function(entity)
                TriggerEvent('nyx:inventory:openPallet', entity)
            end
        }
    },
    distance = 2.5
})
```
