# 📦 Part 6/10: Zero-Sum Supply Chain & Logistics Engine (`nyx_logistics`)

> **Spec Purpose:** Authoritative state machine for material extraction, industrial refining pipelines, freight hauling, physical retail shelving, and elastic price discovery.
> 
> **Philosophy:** No static infinite-vendor loops. If players do not harvest ore, smelt metal, assemble tools, and physically haul crates to store shelves, stores run out of stock and shelves sit empty.
> 
>   

## 1. Supply Circuit Architecture

```
[Finite Harvest Node]
        │ (Physical Gathering)
        ▼
 [Raw Bulk Items] (Raw Ore, Crude Oil, Logs)
        │ (Transport via Hauler/Flatbed)
        ▼
[Refining Facility]
        │ (Industrial Conversion Process)
        ▼
[Intermediate Parts] (Steel Plates, Polymers, Fasteners)
        │ (Transport via Van/Truck)
        ▼
[Assembly Workshop]
        │ (Recipe Processing & Quality Modifiers)
        ▼
[Finished Goods] (Repair Kits, Medical Packs, Radios)
        │ (Pallet Logistics & Invoicing)
        ▼
 [Physical Retail Shelf] ──(Dynamic Elastic Pricing)──> [Consumer Purchase]
```

## 2. Dynamic Price Elasticity Model

Items stocked inside public or private retail shelves do not maintain hardcoded price values. Shelf prices float dynamically based on current inventory levels relative to regional capacity.

  

### 2.1 The Elastic Pricing Formula

$$P_{\text{shelf}} = P_{\text{base}} \times \left(1 + \alpha \cdot \frac{C_{\text{target}} - S_{\text{current}}}{C_{\text{target}}}\right)$$

Where:

  

- $P_{\text{base}}$ = Statutorily declared base production value of the item.
    
      
    
- $C_{\text{target}}$ = Ideal equilibrium inventory capacity for that specific shelf unit.
    
      
    
- $S_{\text{current}}$ = Active in-stock quantity ($0 \le S_{\text{current}} \le C_{\text{max}}$).
    
      
    
- $\alpha$ = Shortage sensitivity coefficient (standard default: $\alpha = 1.25$).
    
      
    

### 2.2 Boundary Conditions

- **Surplus Floor:** If $S_{\text{current}} \ge C_{\text{target}}$, price drops towards the production cost floor ($P_{\text{shelf}} \ge 0.50 \times P_{\text{base}}$).
    
      
    
- **Shortage Ceiling:** If $S_{\text{current}} \to 0$, $P_{\text{shelf}}$ automatically caps at $2.25 \times P_{\text{base}}$ to prevent runaway infinite pricing.
    
      
    
- **Empty Shelf Behavior:** If $S_{\text{current}} = 0$, the purchase interaction fails with `OUT_OF_STOCK`, triggering a priority freight contract request on the public hauler dispatch board.
    
      
    

## 3. Database Schema: Supply Nodes, Factories & Shelves

### 3.1 SQL Migration Definition

SQL

```
-- Finite natural extraction points
CREATE TABLE IF NOT EXISTS `nyx_logistics_nodes` (
  `node_id` VARCHAR(64) PRIMARY KEY, -- e.g., 'mine_quarry_01', 'oil_well_sandy'
  `resource_item` VARCHAR(64) NOT NULL,
  `current_reserve` INT UNSIGNED NOT NULL,
  `max_reserve` INT UNSIGNED NOT NULL,
  `regen_rate_per_hour` INT UNSIGNED NOT NULL,
  `coords` JSON NOT NULL, -- {"x": 2950.1, "y": 2780.4, "z": 41.2}
  `last_harvested_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX `idx_resource` (`resource_item`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Processing, refining, and assembly facilities
CREATE TABLE IF NOT EXISTS `nyx_logistics_facilities` (
  `facility_id` VARCHAR(64) PRIMARY KEY,
  `owner_faction_id` VARCHAR(64) NULL, -- NULL indicates public/cooperative facility
  `type` ENUM('refinery', 'smelter', 'assembly', 'chemical') NOT NULL,
  `input_inventory_id` VARCHAR(64) NOT NULL,
  `output_inventory_id` VARCHAR(64) NOT NULL,
  `power_grid_id` VARCHAR(32) NOT NULL,
  `is_active` TINYINT(1) DEFAULT 0,
  `active_recipe` VARCHAR(64) NULL,
  `progress` DECIMAL(5, 2) DEFAULT 0.00, -- 0.00 to 100.00%
  INDEX `idx_owner` (`owner_faction_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Physical shelf containers tied to points of sale
CREATE TABLE IF NOT EXISTS `nyx_logistics_shelves` (
  `shelf_id` VARCHAR(64) PRIMARY KEY, -- e.g., 'pos:247_vinewood:shelf_drinks'
  `store_id` VARCHAR(32) NOT NULL,
  `target_capacity` INT UNSIGNED NOT NULL DEFAULT 100,
  `item_id` VARCHAR(64) NOT NULL,
  `base_price` DECIMAL(10, 2) NOT NULL,
  `current_price` DECIMAL(10, 2) NOT NULL,
  `inventory_id` VARCHAR(64) NOT NULL,
  `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX `idx_store` (`store_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Public freight contracts generated dynamically by shortages
CREATE TABLE IF NOT EXISTS `nyx_logistics_contracts` (
  `contract_id` BIGINT AUTO_INCREMENT PRIMARY KEY,
  `source_inventory_id` VARCHAR(64) NOT NULL,
  `dest_shelf_id` VARCHAR(64) NOT NULL,
  `item_id` VARCHAR(64) NOT NULL,
  `quantity` INT UNSIGNED NOT NULL,
  `payout_per_unit` DECIMAL(10, 2) NOT NULL,
  `issuer_faction_id` VARCHAR(64) NOT NULL,
  `status` ENUM('available', 'in_transit', 'completed', 'expired') DEFAULT 'available',
  `claimed_by_char_id` INT NULL,
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  INDEX `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 4. Finite Extraction & Harvesting Engine

Harvesting is not a client-side animation loop that grants items directly. The server validates line-of-sight, tool requirements, node reserves, and extraction rates.

  

```
Client Input (Target Node Raycast)
               │
               ▼
   [RPC: logistics:harvestNode]
               │
               ▼
    [Server Validates Coords] ──(Distance > 3.0m)──> [Reject: OUT_OF_RANGE]
               │
               ▼
     [Check Required Tool] ────(Durability == 0)───> [Reject: TOOL_BROKEN]
               │
               ▼
     [Verify Node Reserves] ───(Reserve == 0)──────> [Reject: NODE_DEPLETED]
               │
               ▼
     [Acquire Node Mutex Lock]
     ├── Decrement node current_reserve
     ├── Allocate dynamic item metadata (Purity, Batch, Source)
     ├── Insert item into player inventory via nyx_inventory engine
     └── Schedule regen interval
               │
               ▼
     [Release Lock & Stream Sync to Observers]
```

### 4.1 Node Replenishment Routine

Lua

```
-- server/nodes.lua
Nyx = Nyx or {}
Nyx.Logistics = Nyx.Logistics or {}
Nyx.Logistics.ActiveNodes = {}

function Nyx.Logistics.ProcessRegenerationTick()
    local now = os.time()
    
    for nodeId, node in pairs(Nyx.Logistics.ActiveNodes) do
        if node.current_reserve < node.max_reserve then
            local elapsedHours = (now - node.last_harvested) / 3600
            if elapsedHours >= 0.25 then -- Process every 15 minutes minimum
                local recovered = math.floor(elapsedHours * node.regen_rate_per_hour)
                if recovered > 0 then
                    node.current_reserve = math.min(node.max_reserve, node.current_reserve + recovered)
                    node.last_harvested = now
                    
                    MySQL.query.await([[
                        UPDATE nyx_logistics_nodes 
                        SET current_reserve = ?, last_harvested_at = CURRENT_TIMESTAMP 
                        WHERE node_id = ?
                    ]], { node.current_reserve, nodeId })
                end
            end
        end
    end
end
```

## 6. Physical Freight, Pallets & Trucking

### 6.1 Pallet Object Model

- Large-scale freight does not fit in character backpacks ($30\text{ kg}$ max limit).
    
      
    
- Bulk materials pack into physical pallet containers ($500\text{ kg} - 2,000\text{ kg}$ weight capacity).
    
      
    
- Pallets spawn as synchronized physical props (`prop_boxpile_06a`, `prop_pallet_01a`).
    
      
    
- Players move pallets using forklifts (`forklift`), pallet jacks, or commercial flatbeds (`flatbed`, `mule`, `pounder`).
    
      
    

### 6.2 Hauling Contract Handshake

1. Stores experiencing critical inventory deficits generate a row in `nyx_logistics_contracts`.
    
      
    
2. A logistics hauler accepts the contract via dispatch terminal.
    
      
    
3. The hauler physically picks up freight at the distribution hub and loads the vehicle.
    
      
    
4. Upon delivery to the target retail zone:
    
      
    - Server transfers items from the vehicle inventory directly to the destination shelf inventory.
        
          
        
    - Payout triggers automatically: freight charges debit from the store account and credit to the hauler.
        
          
        
    - Dynamic price recalibrates downwards on the newly stocked shelf.
        
          
        

## 7. Network RPC Interface (`nyx_logistics`)

|**RPC Route**|**Caller**|**Arguments**|**Data Returned / Action**|
|---|---|---|---|
|`logistics:harvestNode`|Client|`nodeId, toolSlot`|Harvest progress validation, updates node reserve|
|`logistics:getFacilityState`|Client|`facilityId`|Power availability, active recipe, input/output slot matrix|
|`logistics:startProduction`|Client|`facilityId, recipeKey, batchCount`|Validates ingredients in input inventory; locks containers and sets state to active|
|`logistics:buyFromShelf`|Client|`shelfId, quantity`|Deducts consumer funds, routes municipal sales tax, ejects item to player, recalibrates price|
|`logistics:claimContract`|Client|`contractId`|Binds logistics contract to citizenId; sets status to `in_transit`|

## 9. Verification & Test Criteria

- [ ] **Finite Harvest Depletion:** Drain a copper node to $0$ reserves; verify subsequent client interaction attempts reject with `NODE_DEPLETED` without granting items.
    
      
    
- [ ] **Shelf Stock Out:** Buy all remaining items from a shelf container; confirm the shelf visually renders empty, the item state becomes unpurchasable, and a public logistics contract appears on the municipal board.
    
      
    
- [ ] **Price Elasticity Precision:** Verify that an item with $P_{\text{base}} = 100$ and $C_{\text{target}} = 100$ costs exactly $\$225.00$ when $S_{\text{current}} = 0$, and drops to $\$100.00$ when restocked to $S_{\text{current}} = 100$.
